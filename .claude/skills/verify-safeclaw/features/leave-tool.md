# 연차 일수 계산

`/tools/leave` 는 이름과 입사일을 줄 단위로 붙여넣으면 브라우저 안에서 입사일 기준 연차 발생일수를 바로 계산해 표로 보여 주는 도구다. 대장 값을 함께 넣으면 차이를 대조하고, 결과를 엑셀로 내려받을 수 있다. 법률 자문이 아니라 계산을 도와주는 참고 도구라는 문구가 화면에 있다.

## Sub-features

- `leave-input` `이름과 입사일 붙여넣기` textarea 가 있다.
- `leave-autocalc` 붙여넣는 즉시 「N명 계산」과 결과 표가 나온다(계산 단추 없음).
- `leave-table` 표 머리 = 이름·입사일·부여일수·대장·판정·적용 근거. 부여일수는 숫자.
- `leave-wording` 「노무사」 표기가 없다.

## How to get to it (user POV)

- `/tools/leave` 를 연다(첫 화면 메뉴에는 없다. 주소 직접 입력 또는 링크).
- 예시 넣기 단추로 샘플을 채우거나, 엑셀 명단을 그대로 붙여넣는다.

## Driving it with verify.mts

Preconditions:

- 인스턴스 OK. 로그인 불필요. 외부 키 불필요(계산은 브라우저 안).

- **열기.** `/tools/leave` 를 390×844 로 연다. `getByLabel("이름과 입사일 붙여넣기")` 1개. 스크린샷 `01-leave-empty.jpg`.
- **입력.** `작업자A<TAB>2024-03-01` 과 `작업자B<TAB>2026-01-15` 두 줄을 채운다. 「2명 계산」이 보일 때까지 기다린다.
- **표.** 첫 `table` 의 `th` 에 이름·입사일·부여일수·대장·판정·적용 근거가 전부 있고, 첫 행 3번째 칸이 숫자. 스크린샷 `02-leave-result.jpg`.
- **증거.** 본문 「노무사」 0, 콘솔 오류 0. 명령: `… drive --feature leave-tool [--base URL]`.

## Gotchas

- 계산 기준일은 마운트 직후 한 프레임 비어 있다. 입력 직후 바로 표를 읽지 말고 「N명 계산」을 기다린다.
- 연차 발생일 당일 경계에서 결과가 달라진다. 합성 입사일은 오늘과 1년·2년 차 경계가 겹치지 않는 날짜를 쓴다.
- 화면의 「법률 자문이 아니라 계산을 도와드리는 도구」 문장 때문에 「자문」이 본문에 있다. 이 기능에서는 「노무사」만 센다.
- 결과 엑셀 내려받기는 이 조리법에 없다(내보내기는 작업공간 기능에서 증명).
