# SafeClaw 상업화 디자인/UX + AI Teammate 구현 계획 (2026-07-02)

목적: ① 노동부 공모전 본선 ② SparkClaw 창업가 1기 면접 — "상품 출시 가능 수준"의 기능·디자인.
근거: www.safeclaw.kr 실사 스크린샷(랜딩·워크스페이스), prod 산출물 검증, SparkClaw 공식 페이지 2건 분석.

## 1. 현재 상태 진단 (실사 기반)

### 잘하고 있는 것 (지킬 것)
- **블랙+옐로 아이덴티티**: 산업안전 테이프 색상과 정확히 공명 — 카테고리 적합성이 높고 경쟁 안전앱(파랑 일색)과 차별됨. 버릴 이유 없음.
- 워크스페이스 정보 설계: 5단계 흐름(입력→확인→초안→전파→기록), 12문서 카드 그리드, 근거 연결(기상청/Law.go/Work24/KOSHA) 상태 노출 — 신뢰 구조가 UI에 있음.
- 카피: "오늘 작업을 한 줄로, 실행 가능한 안전 문서팩으로" — 명확.

### 문제 (상업용 기준)
| # | 문제 | 심각도 |
|---|---|---|
| D1 | **테마 단절**: 랜딩=블랙 터미널, 워크스페이스=라이트 — 다른 제품처럼 보임. 브랜드 시스템 부재 | 高 |
| D2 | **레이아웃 붕괴/여백**: 1568px 뷰포트에서 콘텐츠가 좌측으로 몰리고 우측 ~25% 빈 공백, 랜딩 스크롤 시 흰 영역 노출(캔버스 폭 버그로 보임) | 高 |
| D3 | **타깃 부적합 톤**: `safeclaw/os`, `safeclaw@workspace ~ %` 터미널 연출은 개발자 감성 — 구매자(40-50대 현장소장·사업주)에게 이질적. 단, AI-native 심사자(SparkClaw)에겐 강점 → 재해석 필요(아래 3장) | 中 |
| D4 | **140초 생성 대기 UX**: 진행률·문서별 완료 표시 없음(스피너뿐). 상업 제품에서 2분 무반응은 이탈 | 高 |
| D5 | 랜딩 히어로 우측 터미널 패널이 거대한 빈 검정 박스 — 첫 화면의 절반이 공백 | 中 |
| D6 | 모바일 미검증(현장 사용자는 폰) + HTML export가 `<pre>` 평문 | 中 |
| D7 | 신뢰 장치 부족: 가격/도입 절차/고객 사례/보안 안내 등 상업 SaaS 표준 페이지 없음(로그인은 있으나 온보딩 스토리 부재) | 中 |

## 2. 디자인 방향 (권고 1안)

**"산업안전 테이프 × AI 팀원 콘솔"** — 블랙+옐로 유지, 터미널 은유를 "해커 콘솔"에서 **"AI 안전관리자가 일하는 모습이 보이는 창"**으로 재해석.

- 디자인 토큰 통일: 배경(웜 화이트/딥 블랙 2모드 아님 — **라이트 단일** + 블랙은 히어로·푸터 밴드로만), 옐로 #FFD400 계열 1개, 잉크 1개, 보더/뮤트 스케일. Pretendard 유지.
- 랜딩 = 라이트 기반 + 상단 블랙 밴드(현 아이덴티티 계승). 워크스페이스와 동일 토큰 → 단절 해소(D1).
- 컨테이너 max-width 1200~1280 중앙 정렬로 D2 해결.
- 히어로 우측 빈 터미널 → **라이브 데모 콘솔**(아래 Teammate 콘솔의 재생 버전: 실제 생성 로그 리플레이 애니메이션)로 교체(D5).

## 3. AI Agent Teammate 구현 (SparkClaw 직결)

SparkClaw 평가 기준: "AI를 도구가 아니라 **팀 구조 안의 역할**로 설계했는가". SafeClaw의 정답 포지셔닝:

> **"SafeClaw는 안전관리 기능이 아니라, 채용하지 않은 안전관리자입니다."**

구현 항목 (제품에서 체감되게):

### F1. 에이전트 페르소나 + 작업 콘솔 [면접 킬러 기능]
- 생성 대기 140초를 **"AI 안전관리자가 일하는 과정"으로 시각화**: "법제처에서 산안법 근거 조회 중… ✓ / 기상청 안산 실황 확인 — 폭염 신호 감지 ✓ / 위험성평가 작성 중(Claude)… ✓ 12/18" — 이미 status.detail에 이 데이터가 전부 있음. **D4 해결과 동일 작업**.
- 완료 시 "오늘 문서팩 준비했습니다. 특이사항 2건: 폭염 주의보 반영, 외국인 3명 다국어 브리핑 포함" — 팀원의 보고 형태.

### F2. 아침 자동 브리핑(스케줄드 에이전트)
- 사업장 프로필 저장 → 매일 아침 6시 해당 현장 기상·특보 확인 후 "오늘 TBM 준비됐습니다" 문서팩 자동 생성+메일/문자 발송(기존 n8n 전파 재사용).
- "사람이 시키지 않아도 출근해 있는 팀원" — 도구→프로세스 통합의 증명. (기술: Vercel cron + 기존 파이프라인)

### F3. 메이커 스토리 = 운영 증거
- 면접 자료: SafeClaw 자체가 AI 팀으로 개발·운영됨 — 오늘 하루 기록이 그 증거(자율 에이전트 루프로 PR 7건 머지·배포, 멀티에이전트 교차 검증으로 치명 결함 11건 발굴, AI 구현자→AI 리뷰어 SDD 파이프라인 가동 중, 주 1회 자동 smoke). "1인 창업자 + AI 팀원 N명" 조직도를 그릴 수 있음.
- 산출물: 면접용 1페이지 "AI 팀 조직도 + 운영 로그" 문서 별도 작성.

## 4. 실행 배치 (현행 SDD 콘텐츠 배치 완료 후)

| 배치 | 항목 | 규모 |
|---|---|---|
| D-1 | 디자인 토큰 통일 + 레이아웃(max-width) 수정 + 랜딩 재구성(D1·D2·D5) | 中 |
| D-2 | **생성 진행 콘솔(F1)** — status 스트리밍 or 폴링 + 문서 카드 실시간 완료 표시(D4) | 中 |
| D-3 | 아침 자동 브리핑(F2) — 사업장 프로필 + cron + 발송 | 中~大 |
| D-4 | 모바일 반응형 점검 + HTML export 표 렌더(D6) | 小~中 |
| D-5 | 신뢰 페이지(가격·도입·보안) + 온보딩(D7) | 小 |
| D-6 | 면접 자료: AI 팀 조직도 + 운영 로그 1페이저(F3) | 小 |

권장 순서: D-2(F1) → D-1 → D-6 → D-3 → D-4 → D-5.
D-2를 최우선으로 두는 이유: 공모전 시연·SparkClaw 면접·상업 UX 세 문제를 한 번에 해결하는 단일 기능이기 때문.
