# Share Recipient Portal Localization

Date: 2026-07-18

## Purpose

The recipient portal at `/share/[sessionId]` now presents the worker-facing chrome in the selected worker language for Vietnamese and English, while keeping Korean as the default fallback.

This is a launch-focused patch for video capture and foreign-worker distribution. It does not change the share session security model, provider dispatch, database schema, or recipient access policy.

## Scope

- Localized page shell, section headings, confirmation form labels, status labels, loading/error guidance, document section labels, and confirmation success messages.
- Localized the initial portal chrome from `lang` / `language` query parameters before a share session is loaded, so invalid or blocked session states do not fall back to Korean during worker video capture.
- Preserved the existing invited-worker scoped flow.
- Preserved the Vietnamese recipient message body generated by the share payload.
- Added browser contract coverage that verifies Vietnamese chrome and confirmation messages are rendered, that the fallback/loading state honors the requested language, and that the old Korean `열람 확인` button text is not shown in the Vietnamese recipient path.
