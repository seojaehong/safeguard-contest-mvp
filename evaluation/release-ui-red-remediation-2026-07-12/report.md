## Root causes

### Desktop workspace border geometry

The unified workspace container used a one-pixel border inside the grid box.
That moved the sidebar and main content from `117.047` to `118.047` and extended
the short-screen sidebar bottom from the intended `639.047` to `640.047`.

The desktop container now uses a one-pixel inset outline instead of an inner
border. The visible boundary is preserved while the sidebar and main content
begin at the container coordinate. Day and Night keep identical geometry.

### Mobile workspace adjacency contract

The mobile sidebar already ended exactly where the main content began:
`260.046875 == 260.046875`. There was no overlap or horizontal overflow. The
old test required an additional eight-pixel gap that the product design never
rendered.

Commit `5168797` corrected that expectation but rounded both DOMRect edges to
integer CSS pixels before comparing them. That allowed a subpixel overlap or
gap below half a pixel to appear equal. The follow-up preserves raw
`top`/`bottom`/`left`/`right` coordinates and applies an explicit `0.01` CSS-pixel
measurement tolerance. Synthetic `260.4` versus `260.2` overlap and gap cases
are both rejected, so a `0.2` CSS-pixel drift cannot pass. The product CSS did
not require another change.

### Module content starting position

The mobile module decision header used 16px vertical padding. That pushed the
first document content to `351.359`, eleven pixels beyond the workspace-derived
limit. Reducing the header's vertical padding to 4px moves the content up by
24px while retaining 12px horizontal padding and the 44px command controls.

Measured content starts:

| Route | Before | After |
| --- | ---: | ---: |
| `/home` | 328.969 | 304.969 |
| `/documents` | 351.359 | 327.359 |
| `/reports` | 359.578 | 335.578 |
| `/settings/ai-connect` | 327.000 | 303.000 |

The same values apply to Day and Night. All measured horizontal overflows are
zero.

## Visual review

The before/after desktop short-screen, workspace mobile, and document mobile
captures are stored in this directory. Direct review found no text clipping,
incoherent overlap, or horizontal overflow. The workspace mobile before/after
files are byte-identical because its product layout was already correct; only
the stale gap expectation changed.
