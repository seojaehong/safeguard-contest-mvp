Browser Supabase clients and canonical owner policies support direct authenticated REST as a distinct path from service-role application access; exploitation requires a valid account and foreign UUID. ## Root Cause

The violated invariant is that worker rows can reference another tenant's site. Current source instead shows: site_id is an independent foreign key, while WITH CHECK proves only that workers.organization_id belongs to auth.uid(); it never proves sites.organization_id equals the row organization_id.

  on workers for all
  using (
    exists (
      select 1 from organizations
      where organizations.id = workers.organization_id
        and organizations.owner_id = auth.uid()
    )
  )

    exists (
      select 1 from organizations
