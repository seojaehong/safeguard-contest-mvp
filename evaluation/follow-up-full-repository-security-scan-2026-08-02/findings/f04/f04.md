## Validation

Method: Static public route through local-corpus and remote-catalog trace

Result count is capped, but query/filter lengths and request rate are not, and each request can load/search local assets and invoke remote catalog retrieval.

Limitations:
- Caching may reduce repeated local loads but is not a distributed request control.
- Production cache lifetime and external edge throttling are unknown.

## Dataflow

Unauthenticated safety-reference q/filters/frequency -> public search route -> local corpus/exact bundle loading and remote catalog search -> serverless I/O/CPU and Supabase/provider work.

## Severity

**medium**. The matrix maps medium impact and high likelihood to medium because remote repetition is easy but the evidence does not establish sustained high-impact outage.

## Remediation

Apply query-size, result-count, timeout, and durable public rate budgets before loading the corpus or calling the remote catalog.

Regression tests:
- Reject oversized queries before corpus or network work.
- Throttle repeated public searches and cap returned result work.
