## Summary

Public legal search lacks request rate and query-size budgets before multi-provider retry fan-out. Public Next.js route is directly remote-reachable in the product source; each request can fan out before result slicing, and no repository rate, concurrency, or query-size control precedes work.

## Root Cause

The violated invariant is that public legal search can amplify unbounded provider work. Current source instead shows: Unauthenticated GET accepts q without a length check or limiter and immediately calls runSearch; supporting implementation performs primary, fallback, secondary, and precedent provider searches with retries, so repeated requests can consume provider and server resources.

Limitations:

## Dataflow

Unauthenticated GET q/frequency -> /api/search without query or rate budget -> runSearch -> multiple legal-provider branches with retries/timeouts -> serverless/provider work.

## Reachability

Public Next.js route is directly remote-reachable in the product source; each request can fan out before result slicing, and no repository rate, concurrency, or query-size control precedes work.

Counterevidence: Per-provider timeouts and result caps bound individual outputs, but they do not bound request frequency or aggregate provider attempts; external edge throttling is unverified.

## Severity

**medium**. The matrix maps medium impact and high likelihood to medium: unauthenticated amplification is straightforward, while sustained outage or material cost is not proven strongly enough for high impact.

Change conditions: Raise if production telemetry proves sustained outage/material provider cost at modest effort; lower if a verified edge or distributed work budget covers this route before provider fan-out.

## Remediation

Reject oversized queries, apply a shared public-request budget before provider fan-out, and enforce a durable IP or abuse-token rate limit with bounded retries.

Regression tests:
- Reject oversized legal queries before any provider call.
- Assert repeated public requests are throttled before retry fan-out.
