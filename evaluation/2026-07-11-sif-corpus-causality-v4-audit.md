# SafeClaw SIF 코퍼스 인과성 감사

검증일: 2026-07-11
대상: `evaluation/sif-embedding-gate/sif-embedding-corpus.jsonl`

## 판정

자동 게이트를 통과했다. 이번 판정은 코퍼스 전체의 의미가 완벽하다는 선언이 아니라, 현재 운영 변환기가 아래 무결성 조건을 만족했다는 뜻이다.

- 기준 코퍼스 6,032행과 파일 SHA-256 일치
- 두 번 실행한 운영 변환 결과의 해시 일치
- 입력 레코드 변이 없음
- 원본 `controls` 배열 별칭 재사용 없음
- 위험 태그가 단독 통제문으로 새는 사례 없음
- 정의된 인과 오분류 플래그 없음
- 모든 행이 하나의 감사 분기로 집계됨

실행 명령:

```text
npm.cmd run audit:sif-causality -- --output evaluation/2026-07-11-sif-corpus-causality-v4-audit.jsonl
```

## 이번 보강

- 장비명만 등장하는 원인 미확정 SIF는 기계 방호·LOTO를 확정하지 않고 검토 필요로 닫는다.
- 컨베이어가 문장에 우연히 등장한 추락·협착 사례를 컨베이어 상부 통행으로 오인하지 않도록 작업자 위치 신호를 좁혔다.
- 쇄석기 로터 원석 제거, 파쇄기 투입구 추락, 크레인 버킷 충돌, 자동화 이재기 협착을 전용 인과 분기로 분리했다.
- 고소작업대 가드 걸림 해소, 파렛트 임시 발판, 세탁물 운반물 밀림, 크레인 매달림 하중 탑승, 굴삭기 버킷 탑승을 원문 원인에 맞는 조치로 분리했다.
- 감사기는 제품 분류기와 같은 사고개요 추출 함수를 사용한다.
- 행 수뿐 아니라 기준 파일 해시와 인과 플래그도 종료 게이트에 포함했다.

## 한계와 운영 원칙

- 정규식 기반 전수 감사는 모든 문장의 산업안전 의미를 자동 확정하지 않는다.
- 원인이 충분하지 않은 1,252행은 확정 조치를 만들지 않고 `reviewRequired`로 보존한다.
- 신규 코퍼스나 최신 SIF 자료가 들어오면 행 수와 파일 해시 기준을 명시적으로 갱신하고 같은 감사를 다시 실행해야 한다.
- 임베딩 생성·Supabase 업로드·published ontology 승격은 이번 작업에서 수행하지 않았다. 별도 승인 게이트를 유지한다.

기계 판독용 전체 결과는 `evaluation/2026-07-11-sif-corpus-causality-v4-audit.jsonl`에 있다. 이 파일은 실행 산출물이며 코드 커밋에는 포함하지 않는다.
