[특수 대상/조건]
- 신규 투입자 1명 포함 — 작업중지 기준과 보호구 착용을 별도 복창 확인

[핵심 판단]

1. 작업 전 비계 고정핀, 바퀴 잠금, 작업발판 상태 점검
2. 풍속 상승 또는 돌풍 체감 시 즉시 작업중지 후 지상 대기
3. 작업반장 주도로 보호구 착용과 작업구간 출입통제를 확인

[문서팩 구성]
- 위험성평가표: 위험요인, 감소대책, 담당자, 확인 근거
- 작업계획서: 작업구간, 작업순서, 장비·인원, 작업중지 기준
- TBM 및 일일점검: 작업 전 질문, 참석자 확인, 작업 전·중·후 확인
- 안전보건교육: 교육대상, 교육내용, 이해도 확인, 후속 교육
- 비상대응: 즉시조치, 보고체계, 현장보존, 재발방지
- 사진/증빙: 조치 전·후 사진, 설명, 확인자

# 작업계획서

작업계획서(초안)
현장 서식 기준: 작업구간, 작업순서, 장비·인원, 허가·첨부, 확인자 중심

공사명: 서울 성수동 근린생활시설 현장
작업구간: 이동식 비계 사용 외벽 도장, 자재 상하차, 하부 통제
작성자: 관리감독자 / 작업반장
확인자: 현장소장 / 안전관리자
작성일: 작업 시작 전

[1. 작업개요]
- 작업명: 외벽 도장 작업
- 작업내용: 세이프건설 서울 성수동 근린생활시설 외벽 도장 작업
- 작업인원: 5명
- 작업 전 조건확인: 오후 강풍 예보, 작업중지 기준 공유 필요

[2. 작업순서 및 안전조치]
- 작업 전 작업구역 설정, 보호구 확인, 장비 상태 점검
- 주요 작업 수행: 이동식 비계 사용 외벽 도장, 자재 상하차, 하부 통제
- 단계별 안전조치: 작업 전 비계 고정핀, 바퀴 잠금, 작업발판 상태 점검 / 풍속 상승 또는 돌풍 체감 시 즉시 작업중지 후 지상 대기 / 작업반장 주도로 보호구 착용과 작업구간 출입통제를 확인
- 특수 조건 안전조치: 신규 투입자 1명 포함 — 작업중지 기준과 보호구 착용을 별도 복창 확인
- 특수 조건 안전조치: 강풍 조건 — 작업중지 기준과 대피 위치를 작업 전 공유
- 작업 중 위험구역 출입통제와 작업중지 기준 수시 확인
- 작업 종료 후 정리정돈, 잔여 위험요인 확인, 사진/기록 보관

[3. 장비·인원·허가 확인]
- 장비/도구: 작업계획서 또는 안전작업허가서 첨부자료로 확인
- 작업자: 신규 투입자, 외국인 근로자, 협력업체 인원 별도 확인
- 허가/첨부: 고위험 작업은 안전작업허가서, 위험성평가표, TBM 기록을 함께 보관

[4. 작업중지 기준]
- 강풍 시 작업중지 판단은 누가 하고, 팀원에게 어떻게 전파할 것인가?
- 이동식 비계 고정상태와 보호구 착용은 누가 상호 확인했는가?
- 지게차 동선 접근금지 구역과 신호수 위치를 전원이 알고 있는가?

[5. 확인 근거]
- 위험성평가표, TBM 기록, 안전보건교육 기록, 사진/영상 증빙을 같은 문서팩으로 묶어 확인합니다.

# 작업허가 및 안전점검표

안전작업허가 확인서(초안)
현장 적용 전 관리감독자와 허가권자가 작업조건을 최종 확인합니다.

[1. 허가 기본정보]
- 현장명: 서울 성수동 근린생활시설 현장
- 허가대상 작업: 외벽 도장 작업
- 허가구분: 고소작업
- 작업내용: 세이프건설 서울 성수동 근린생활시설 외벽 도장 작업
- 작업인원: 5명
- 작업시간: 작업 시작 전 허가 시각부터 종료 확인 시각까지
- 허가상태: 작업 전 조건 확인 및 허가권자 승인 필요

[2. 작업 전 허가조건]
- 핵심 위험: 강풍 상황에서 이동식 비계가 흔들리며 작업자가 추락하거나 비계가 전도될 위험
- 안전조치 1: 작업 전 비계 고정핀, 바퀴 잠금, 작업발판 상태 점검
- 안전조치 2: 풍속 상승 또는 돌풍 체감 시 즉시 작업중지 후 지상 대기
- 안전조치 3: 작업반장 주도로 보호구 착용과 작업구간 출입통제를 확인
- 허가 전 조건확인: 오후 강풍 예보, 작업중지 기준 공유 필요
- 보호구: 작업별 보호구의 종류, 손상 여부, 착용 상태를 작업 시작 전에 확인

[3. 격리·차단 및 첨부 확인]
- 전원·화기·장비·차량 등 작업구역에 영향을 주는 에너지원의 차단 상태를 확인
- 취급 물질이 있으면 SDS·GHS 경고표지와 보호구 적합성을 추가 확인
- 위험성평가표, 작업계획서, TBM 기록을 같은 작업허가 묶음으로 확인
- 출입통제, 감시자·신호수 배치, 비상연락 수단을 현장에서 확인

[4. 작업 중 확인]
- 작업중지 기준: 강풍 시 작업중지 판단은 누가 하고, 팀원에게 어떻게 전파할 것인가?
- 변경관리 확인: 이동식 비계 고정상태와 보호구 착용은 누가 상호 확인했는가?
- 작업조건이나 작업자가 바뀌면 기존 허가를 그대로 사용하지 않고 재확인

[5. 종료 확인]
- 작업 종료 후 공구·자재·폐기물을 정리하고 잔류 위험을 확인
- 격리·차단 해제와 재가동은 허가권자와 설비 담당자가 함께 확인
- 종료시간, 종료상태, 확인자, 특이사항을 기록한 뒤 허가를 닫음

[6. 확인자]
- 작업책임자: 작업 전 조건 확인
- 관리감독자: 허가조건·보호구·격리 상태 확인
- 허가권자: 작업 시작 승인 및 종료 확인
