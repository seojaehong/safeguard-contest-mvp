작업계획서(초안)
현장 서식 기준: 작업구간, 작업순서, 장비·인원, 허가·첨부, 확인자 중심

공사명: 경기 안산 제조공장
작업구간: 금속 절단, 아크 용접, 가연물 통제, 화재감시
작성자: 관리감독자 / 작업반장
확인자: 현장소장 / 안전관리자
작성일: 작업 시작 전

[1. 작업개요]
- 작업명: 용접·절단 화기작업
- 작업내용: 그린메탈 경기 안산 공장 배관 용접·절단 화기작업
- 작업인원: 6명
- 작업조건: 고온 작업조건, 온열질환 예방과 휴식 기준 공유 필요

[2. 작업순서 및 안전조치]
- 작업 전 작업구역 설정, 보호구 확인, 장비 상태 점검
- 주요 작업 수행: 금속 절단, 아크 용접, 가연물 통제, 화재감시
- 단계별 안전조치: 화기작업 전 가연물 제거와 소화기 배치, 화재감시자 지정 / 용접면·방염장갑·보안경 등 보호구 착용 상태 확인 / 국소배기와 환기설비를 가동하고 밀폐구역 작업을 제한
- 특수 조건 안전조치: 외국인 근로자 2명 포함 — 쉬운 한국어와 다국어 안내로 이해 여부를 확인
- 특수 조건 안전조치: 신규 투입자 1명 포함 — 작업중지 기준과 보호구 착용을 별도 복창 확인
- 특수 조건 안전조치: 화재감시자 지정 — 화기작업 중 불티 비산과 가연물 상태를 상시 확인
- 작업 중 위험구역 출입통제와 작업중지 기준 수시 확인
- 작업 종료 후 정리정돈, 잔여 위험요인 확인, 사진/기록 보관

[3. 장비·인원·허가 확인]
- 장비/도구: 작업계획서 또는 안전작업허가서 첨부자료로 확인
- 작업자: 신규 투입자, 외국인 근로자, 협력업체 인원 별도 확인
- 허가/첨부: 고위험 작업은 안전작업허가서, 위험성평가표, TBM 기록을 함께 보관

[4. 작업중지 기준]
- 오늘 작업구역에서 제거되지 않은 가연물은 없는가?
- 화재감시자와 비상소화 설비 위치를 모두 알고 있는가?
- 환기 불량 구역에서 작업중지 기준을 공유했는가?

[5. 확인 근거]
- 위험성평가표, TBM 기록, 안전보건교육 기록, 사진/영상 증빙을 같은 문서팩으로 묶어 확인합니다.
